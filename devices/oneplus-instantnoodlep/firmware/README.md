# Firmware for oneplus-instantnoodlep (OnePlus 8 Pro)

The device package does not depend on the upstream proprietary firmware
package and does not supply firmware. Follow the repository
[firmware policy](../../../firmware/README.md): extract firmware locally and
record checksums; never commit proprietary blobs. Upstream
`firmware-oneplus-instantnoodlep` downloads a proprietary archive and is not
packaged or depended on here. Device-specific extraction instructions and
checksums have not yet been established.
